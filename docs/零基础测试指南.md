# 零基础测试指南

本指南面向没有编程经验的体验者，帮助你在本地快速启动项目并完成一次完整的功能走查。

## 一、准备工作

1. **安装必备软件**
   - [Python 3.11+](https://www.python.org/downloads/)（安装时勾选“Add python.exe to PATH”）
   - [Node.js 18+](https://nodejs.org/en/download)（默认安装即可）
   - [Git](https://git-scm.com/downloads)

2. **获取项目代码**

   在任意空目录中右键选择“Git Bash Here”或打开终端，运行：

   ```bash
   git clone <你的仓库地址>
   cd <仓库目录>
   ```

## 二、启动后端（FastAPI）

1. 打开终端进入 `backend` 目录：

   ```bash
   cd backend
   ```

2. 创建并启动虚拟环境：

   ```bash
   python -m venv .venv
   # Windows
   .venv\\Scripts\\activate
   # macOS / Linux
   source .venv/bin/activate
   ```

3. 安装依赖并启动服务：

   ```bash
   pip install -r requirements.txt
   uvicorn app.main:app --reload
   ```

   看到 `Application startup complete.` 说明启动成功，保持该窗口不要关闭。

## 三、启动前端（React）

1. 新开一个终端窗口，进入 `frontend` 目录：

   ```bash
   cd frontend
   ```

2. 安装依赖并启动开发服务器：

   ```bash
   npm install
   npm run dev
   ```

   终端会显示访问地址，例如 `http://127.0.0.1:5173`，按住 `Ctrl` 并点击即可在浏览器打开页面。

## 四、5 分钟功能自测流程

> **提示：** 所有验证码都会直接显示在页面上，无需真实收发短信。

1. **注册并登录**
   - 输入任意 11 位手机号（例如 `13800000000`），点击“获取验证码”。
   - 页面会弹出测试验证码，填入后点击“没有账号？点此注册”。
   - 输入微信号（示例：`test_wechat`）并提交，自动完成注册和登录。

2. **查看积分和首页**
   - 首页顶部会显示积分余额、成交率等数据，确认默认积分为 100。

3. **发布一条信息**
   - 在“快速发布信息”卡片中填写：
     - 标题：`测试手机出售`
     - 关键词：`手机,二手`
     - 价格：`1000`
     - 交易类型：选择“出售”
   - 点击“立即发布”，页面提示成功后积分扣除 10 分。

4. **查看信息列表**
   - 在“信息广场”中找到刚才发布的卡片。
   - 点击卡片右下角的“查看联系方式”，会弹出确认，确认后积分再扣 1 分，并自动复制微信号。

5. **反馈成交情况**
   - 点击卡片进入详情页，选择“标记成交”或“暂未成交”，页面会提示处理结果。

6. **退出登录**
   - 返回首页右上角，点击头像并选择“退出登录”，流程结束。

## 五、常见问题

| 问题 | 解决方案 |
| --- | --- |
| 打开 `uvicorn` 终端后看不到提示 | 确保当前终端仍保持激活状态，不要关闭。 |
| 浏览器访问不到前端地址 | 检查前端终端是否仍在运行，以及防火墙是否放行 5173 端口。 |
| 页面提示“网络错误” | 确认后端终端没有报错，且两个服务都在本机运行。 |

完成以上步骤即完成一次完整的“注册 → 发布 → 查看 → 成交”功能链路测试。
