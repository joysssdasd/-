# 交易信息撮合平台

该仓库提供一个积分驱动的 C2C 交易信息撮合平台的完整参考实现与产品需求文档（PRD）。

## 📚 仓库结构概览

```
.
├── README.md                     # 项目介绍与使用说明
├── docs/
│   └── 交易信息撮合平台-产品需求文档.md  # 完整 PRD
├── backend/
│   ├── app/                      # FastAPI 后端服务源码
│   ├── requirements.txt          # 后端依赖列表
│   └── tests/                    # 核心业务集成测试
└── frontend/                     # Vite + React 前端项目
    ├── src/                      # UI 源码
    ├── package.json              # 前端依赖与脚本
    └── .env.example              # 前端接口地址示例配置
```

## ⚙️ 后端服务快速启动

1. **安装依赖**

   ```bash
   cd backend
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. **配置数据库连接**

   默认配置指向示例的 PostgreSQL 数据库。如果需要自建数据库，请在 `backend/.env` 中覆盖以下环境变量：

   ```dotenv
   DATABASE_URL=postgresql+psycopg2://<user>:<password>@<host>:<port>/<database>
   JWT_SECRET_KEY=<自定义密钥>
   ```

3. **启动服务**

   ```bash
   uvicorn app.main:app --reload
   ```

   启动后可访问 `http://127.0.0.1:8000/docs` 查看自动生成的 OpenAPI 文档。

## 🖥️ 前端界面快速启动

1. **安装依赖**

   ```bash
   cd frontend
   npm install
   ```

2. **配置接口地址（可选）**

   如果后端运行在非默认地址，复制 `.env.example` 为 `.env` 并修改 `VITE_API_BASE_URL`。

3. **启动开发服务器**

   ```bash
   npm run dev
   ```

   浏览器访问终端输出的地址（默认 `http://127.0.0.1:5173`），即可体验注册、登录、信息发布、查看、成交反馈等完整交互。

## ✅ 功能要点

- 手机验证码注册 / 登录，支持邀请码关联与奖励。
- 用户积分体系（注册奖励、发布消耗、查看消耗、退还与邀请奖励）。
- 交易信息的发布、搜索、状态管理与联系方式查看。
- 成交确认与成交率自动计算。
- 后端集成测试覆盖核心流程，保障交易闭环稳定性。

## 🧪 测试与自检

### 后端自动化测试

在项目根目录执行：

```bash
cd backend
pytest
```

测试会自动使用 SQLite 数据库，不会影响生产数据。

### 前端手动体验（零基础版）

1. 打开两个终端窗口：
   - 第一个窗口按照“后端服务快速启动”章节运行 `uvicorn`；
   - 第二个窗口按照“前端界面快速启动”章节运行 `npm run dev`。
2. 浏览器访问 `http://127.0.0.1:5173`：
   1. 输入手机号 → 点击“获取验证码”（界面会直接显示测试验证码）。
   2. 选择“没有账号？点此注册”，填写微信号并输入验证码 → 点击“注册并登录”。
   3. 在“快速发布信息”卡片中填写标题、关键词、价格等信息 → 点击发布，确认积分扣减。
   4. 在“信息广场”列表中找到刚发布的卡片 → 点击“查看联系方式”，确认积分流水新增记录。
   5. 打开详情页 → 点击“标记成交”或“暂未成交”以体验成交反馈流程。
3. 若需重新开始，可在仪表盘右上角点击“退出登录”，随后使用验证码登录即可。
